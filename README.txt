# Elite Minerals Connect — Demo Prototype

This is a visual and interactive prototype inspired by the supplied dashboard screenshot.

Included:
- Responsive dashboard layout
- Member directory
- Search and filters
- Buyer / Seller / Broker / Service Provider roles
- "List Yourself" form
- Demo listings stored in the browser's localStorage
- Locked contact details
- Navigation sections
- Mobile-friendly layout

IMPORTANT:
This is a prototype. It does not process payments, verify identities, verify minerals/documents, or provide a real member database.

For a real multi-user site, the next stage is to connect authentication + a database + an admin approval system + secure messaging.

Open index.html to preview it locally.
